# NavInteligente

App de navegación inteligente multi-destino con optimización de rutas usando Google Maps y Waze.

## Funcionalidades
- GPS automático
- Múltiples destinos con autocompletado
- Optimización de ruta (Nearest Neighbor + 2-opt)
- Distance Matrix API (tráfico en tiempo real)
- Mapa interactivo
- Deep link a Google Maps y Waze
